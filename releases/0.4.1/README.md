# Star Swordmaster 0.4.1

Minecraft **1.21.10**, Java 21 og Fabric Loader 0.19.5. Brug Fabric API 0.138.4+1.21.10, Better Combat 3.0.0+1.21.10, PAL 1.1.3 og Cloth Config 20.0.149 fra [installationsvejledningen](../../README.md).

Udskift den gamle Star Swordmaster-JAR med `star-swordmaster-0.4.1.jar`; behold kun én version. Brug **samme version på klient og server**.

Tre nye passive rang 4-opgraderinger: Astralsværdets Suveræn, Den Himmelske Arkon og Formørkelsens Suveræn. Hver kræver sin klasse, Mastery, karakterlevel 25, Sword/Fire-level 20 og ét perkpoint. Præcise effektive statbonusser og +5% skade til klassens kategori vises på H. Træet på K har nu 62 noder, inklusive 15 valgfrie passive træningstrin og tre nye rangikoner.

Tidligere rangbonusser, fordelte stats, point, progression, gemmeformat, aktive evner/animationer og HUD bevares. Ingen nye modafhængigheder.

[Rangkrav og bonusser](../../RANKS.md), [testresultater](VALIDATION.md) og [checksum](SHA256SUMS.txt).
