# Star Swordmaster 0.3.7

Minecraft **1.21.10**, Java 21 og Fabric Loader 0.19.5. Brug de eksisterende Fabric API-, Better Combat 3.0.0+1.21.10-, Player Animation Library 1.1.3- og Cloth Config-afhængigheder fra [installationsvejledningen](../../README.md).

Download `star-swordmaster-0.3.7.jar` og udskift den tidligere Star Swordmaster-JAR på klient og server. Behold kun én version. Eksisterende levels, XP, fordelte stats, lærte evner og point bevares.

Ingen fast karakterlevelgrænse. Belønninger modtaget, mens karakteren allerede er level 8+, giver ×1,5 mod-XP. Hvert level giver stadig 5 statpoint til H og 1 perkpoint til K. Evnebjælken møder vanilla-hotbarens ydre kant uden mellemrum eller overlap. Ressourcepanelets placering er uændret.

[XP-regel og migration](../../LEVELING.md), [testresultater](VALIDATION.md) og [checksum](SHA256SUMS.txt). Alle 32 aktive evners animationer og effekter fra 0.3.6 bevares.
