# Validering — Star Swordmaster 0.3.7

## Ubegrænset leveling og hotbar i version 0.3.7

Verificeret 16. oktober 2026:
- Java 21, Minecraft 1.21.10 og samme Fabric/Better Combat/PAL-afhængigheder som 0.3.6. `./gradlew --offline build smokeClasses test --rerun` består med **97 JUnit-tests**, nul fejl/spring og **37 selvstændige progressionskontroller**. Ingen nye afhængigheder.
- Karakter-XP, level og pointbudgetter bruger eksakte `BigInteger`-beregninger uden fast levelmaksimum. Kravet er fortsat `50 + 20 × level`. Belønninger modtaget ved level 1–7 er uændrede; allerede på level 8+ gives ×1,5. En belønning, der krydser fra 7 til 8, multipliceres ikke. Halve XP bevares mellem belønninger/genindlæsninger. Hvert opnået level giver præcis 5 statpoint og 1 perkpoint, udledt én gang fra level minus forbrug. Minecraft-XP ændres ikke.
- Nye tests dækker niveau 7/8, præcise grænser, flere levels, gentagen lagring, mangelfulde data, 100-cifrede XP-belønninger og levels over `long`-grænsen. Træningshændelser fortsætter efter færdighedslevel 100, men det viste færdighedslevel og evnekravene ændres ikke. Overflow i eksisterende statbonusmultiplikation og køb ved stattypens maksimum er afværget uden nye stats eller ændrede bonuskoefficienter.
- Migration fra gamle schema-1-profiler bevarer både XP-total, level, allerede fordelte stats, lærte evner og pointbeholdninger. En gammel karakter med level 100 / 200.000 XP forbliver level 100 uden retroaktive ekstra point. Ny normal belønning på 1.400 giver 2.100 XP, level 101 og kun ét levels point. Historisk XP-forskydning gemmes med versionsmarkør; gentagen indlæsning gentager ikke migrationen. Gamle mana-/staminamaksima og klassebonusser er kontrolleret. Se [LEVELING.md](../../LEVELING.md).
- Rigtig singleplayer med integreret server består **42 kontroller**. Dedikeret lokal Fabric-server og to samtidige klienter består **42 kontroller for A og 4 for B**. Scenarierne bruger normale sværd-/ildtræningshændelser ved level 7 og 8, H-statkøb, K-perkkøb, stor flerniveaubelønning, gammel level-100-profil, eksakt 100-cifret XP-synkronisering og separat spillerdata. Faktisk død/respawn, genforbindelse og fuldt serverstop/genstart i singleplayer bevarer alle tal uden ekstra point.
- Layout og screenshots er kontrolleret ved **1280×720/skala 2, 960×720/skala 3, 853×481/skala 1 og 640×480/skala 2**. Evnebjælken beholder 182×22 GUI-enheder, fem slots og Z/X/C/V/B; H/K virker fortsat. Minecrafts faktiske bytecode viser native baggrund ved `h−22`, men valgt slots/offhands ydre kant ved `h−23`. Evnebjælken slutter præcis ved `h−23`: nul afstand til yderkanten uden overlap. Den flyttes tre GUI-enheder ned; ressourcepanelet og vanilla-indikatorernes tidligere positioner ændres ikke.
- Den sidste visuelle kontrol afslørede, at ekstreme ressourceværdier var bredere end de eksisterende målere. Kun tal fra 1 milliard formatteres nu kompakt; almindelige tal, ressourceformler, størrelser og placeringer er uændrede. Ny regressionstest og endnu et komplet singleplayer-forløb med 42 kontroller består efter rettelsen. Levelmærket afkortes ved ekstrem bredde; H bevarer fulde level-/XP-/pointtal via eksisterende tooltips.
- Release-JAR har korrekt version 0.3.7, gyldig ZIP-integritet og ingen smoke-klasser. Alle **58 assets** og **33 eksisterende klasser** er byte-identiske med den publicerede 0.3.6, herunder evnelogik, animation/VFX, lagring, attributmodifiers og eksisterende netværksdefinitioner. Ingen ændringer af evneskade, omkostninger, cooldowns, målvalg eller nye runtime-afhængigheder.
- Uafhængig kodegennemgang fandt ingen væsentlige resterende problemer. Lokale spiltests bruger offline-login/virtuel skærm. Efter eksplicitte COMPLETE-markører lukkes testprocesser manuelt; Gradles exit 130 ved denne lukning er ikke et fejlet gameplay-assert. Den almindelige build/test-kommando afslutter med exit 0.
