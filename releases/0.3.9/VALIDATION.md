# Validering — Star Swordmaster 0.3.9

## Evnebjælke under stamina i version 0.3.9

Verificeret 16. oktober 2026:
- `./gradlew --offline build smokeClasses test --rerun` med Java 21 og de eksisterende Minecraft 1.21.10/Fabric/Better Combat/PAL-afhængigheder består: **107 JUnit-tests**, nul fejl/spring, samt **37 selvstændige progressionskontroller**.
- De tre nye placeringstests fejlede mod 0.3.8 før rettelsen; den nye model består. En rigtig render-test fejlede derefter på manglende 75 %-skalering før rendererændringen. Den færdige rendering bruger én 0,75-transformation på det oprindelige layout: faktisk **136,5 × 16,5 GUI-enheder**, ikoner 12 × 12 og uændrede fem slots, labels, rammer og cooldowns. Teksturerne er uændrede; Minecrafts eksisterende ikke-slørede nærmeste-nabo-filter bevares.
- Den rigtige Minecraft-klient med integreret Fabric-server og Better Combat består **94 kontroller**. Capture-mixinen måler hele bjælkens faktiske transformerede fill-kanter og alle fire tildelte ikoners faktiske renderkanter. Bjælken flugter med ressourcebjælkernes venstrekant og starter præcis 2 enheder under stamina. Native hotbar/valgt slot, offhand og XP observeres i selve renderingen.
- Layout og screenshots er kontrolleret ved **1280×720/2, 960×720/3, 853×481/1, 640×480/2, 1256×800/2 og 1260×800/2**. De sidste to tester den nye GUI-breddegrænse 630. Et faktisk udstyret skjold verificerer offhand-afstanden. I brede vinduer bevares ressourcernes position fra 0.3.8; i smalle vinduer flyttes ressourcer og evner samlet op med plads til native luft/rustning. Hele gruppens nederste kant kontrolleres også med ekstra liv og absorption.
- Evner aktiveres via de registrerede **V- og C-taster**, serverens healing/mana/stamina/cooldowns opdateres, og regeneration observeres. Vanilla-hotbarens talgenvej skifter faktisk genstands-slot. Alle Z/X/C/V/B-defaults og H/K bevares. Chatlinks ved skala 1/0,5, maksimal linjeafstand, creative-genstandsnavn, F1, spectator og manglende/sene snapshots består; rendering ændrer ingen spillerdata.
- Fallback-testens gamle tick-assert kunne rammes af et nyt snapshot mellem render og tick. Testen kontrollerer nu synlighed/chat synkront i renderfasen, hvor manglende data simuleres. Ingen produktionsændring var nødvendig for dette testproblem. Hele slutforløbet består efter rettelsen.
- Kodegennemgang fandt ingen produktionsblokeringer; dens to testbemærkninger om snapshots og hele gruppens kant er dækket i det beståede slutforløb. Ingen nye afhængigheder. HUD'en havde ingen museklik til slotvalg, så K-menuens eksisterende klikområder ændres ikke.
- Release-JAR har version 0.3.9, gyldig ZIP-integritet og ingen smoke-klasser. **45 af 48 eksisterende klasser** og alle **58 assets** er byte-identiske med 0.3.8. De eneste ændrede produktionsklasser er `SkillHud`, `SkillHudLayout` og `ResourceHudLayout`. Server, ressourcedata, evner, point, gemmeformat, netværk og XP-kurve/-multiplier er uændrede. XP/sult beholder deres native løft 29 fra 0.3.8. Se [HUD_LAYOUT.md](../../HUD_LAYOUT.md).
- Ingen ny multiplayer-session er kørt for denne HUD-ændring; samtlige server-/netværksklasser er byte-identiske med den tidligere testede udgave. Spiltesten bruger lokal offline-login og virtuel skærm; efter eksplicit COMPLETE lukkes klienten manuelt. Build/test-kommandoen afslutter selv med exit 0.
