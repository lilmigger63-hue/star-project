# Star Swordmaster 0.3.9

Minecraft **1.21.10**, Java 21 og Fabric Loader 0.19.5. Brug samme Fabric API, Better Combat 3.0.0+1.21.10, Player Animation Library 1.1.3 og Cloth Config som i [installationsvejledningen](../../README.md).

Download `star-swordmaster-0.3.9.jar` og udskift den gamle Star Swordmaster-JAR. Behold kun én version; brug samme version på klient og server.

Evnebjælken ligger 2 GUI-enheder under stamina, venstrejusteret med ressourcebjælkerne. Hele bjælken er skaleret ensartet til 75 %: **136,5 × 16,5 GUI-enheder**. Fem slots, Z/X/C/V/B, cooldowns og aktivering bevares. I smalle vinduer stables hele venstre gruppe med plads til offhand, chat og native indikatorer.

Hotbar, XP og sult beholder deres placeringer. Ressourcedata, ubegrænset leveling, ×1,5-XP-reglen fra level 8, stats, point og gemte data er uændrede. [HUD-layout](../../HUD_LAYOUT.md), [testresultater](VALIDATION.md) og [checksum](SHA256SUMS.txt).
