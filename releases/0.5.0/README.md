# Star Swordmaster 0.5.0

[Download JAR](https://raw.githubusercontent.com/lilmigger63-hue/star-project/main/releases/0.5.0/star-swordmaster-0.5.0.jar) · [SHA-256](SHA256SUMS.txt)

Minecraft **1.21.10**, Java **21**, Fabric Loader **0.19.5+**. Brug samme version på klient og server. Udskift den tidligere Star Swordmaster-JAR i `mods`; behold kun én version.

Eksisterende afhængigheder: Fabric API 0.138.4+1.21.10, Better Combat 3.0.0+1.21.10, Cloth Config 20.0.149 og Player Animation Library 1.1.3 (udgiverens kompatible fil hedder `PlayerAnimationLibFabric-1.1.3+mc.1.21.9.jar`).

85 noder, 54 aktive evner, 16 nye elementbesværgelser, seks nye sværdteknikker og personlige vedvarende sværdaurafarver. Fire rangtrin, XP-regler, stats, point, fem slots og HUD bevares. Ingen schema-migration; nye færdigheder starter på nul praksis i eksisterende verdener.
