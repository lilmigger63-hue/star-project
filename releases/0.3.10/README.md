# Star Swordmaster 0.3.10

Minecraft **1.21.10**, Java 21 og Fabric Loader 0.19.5. Brug de eksisterende Fabric API-, Better Combat 3.0.0+1.21.10-, PAL 1.1.3- og Cloth Config-afhængigheder fra [installationsvejledningen](../../README.md).

Download `star-swordmaster-0.3.10.jar` og udskift den gamle Star Swordmaster-JAR. Behold kun én version; brug samme version på klient og server.

XP, leveltal og sult står nu direkte over den uændrede vanilla-hotbar. XP-bjælkens nederste kant flugter med hotbarens faktiske overkant: præcis **0 GUI-enheders afstand**, uden overlap. Level følger XP; sult står over XP. Resten af HUD'en og al progression bevares.

[HUD-layout](../../HUD_LAYOUT.md), [testresultater](VALIDATION.md) og [checksum](SHA256SUMS.txt).
