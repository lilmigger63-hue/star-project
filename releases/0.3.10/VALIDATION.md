# Validering — Star Swordmaster 0.3.10

## XP og sult uden mellemrum over hotbaren i version 0.3.10

Verificeret 16. oktober 2026:
- `./gradlew --offline build smokeClasses test --rerun` med Java 21 og uændrede Minecraft 1.21.10/Fabric/Better Combat/PAL-afhængigheder består: **109 JUnit-tests**, nul fejl/spring og **37 selvstændige progressionskontroller**.
- XP-bjælkens native bund er `h−24`; en forskydning på +1 giver bund **`h−23`**, præcis den valgte hotbar-slots yderkant. XP starter ved `h−28`, sult ved `h−38`, leveltekst ved `h−34`. XP, level og sult flyttes dermed 30 GUI-enheder ned fra 0.3.9 uden overlap med hotbaren. Testen fejlede mod gammel rendering før ændringen.
- Rigtig Minecraft-klient med integreret server og Better Combat gennemfører **101 kontroller**. Capture-mixinen måler XP-bjælkens faktiske transformerede bund og den native valgte slots overkant samt leveltallets faktiske renderposition. De mødes med nul afstand, level følger XP, og sult ligger over XP.
- Testet ved **1280×720/2, 960×720/3, 853×481/1, 640×480/2, 1256×800/2 og 1260×800/2**. Brede og smalle screenshots er visuelt kontrolleret. Resource-/evnegruppen, dens 75 %-skalering, offhand-afstand, chat og øvrige geometritests består uændret. Tastaturaktivering, hotbarvalg, cooldown/ressourcer, ekstra liv/luft, F1, spectator, sene snapshots, creative-genstandsnavne og H/K består igen.
- Den isolerede spiltest afventer nu vanillas færdige spillerindlæsning før opsætning af udstyr. Det første forsøg kunne kontrollere en tom offhand før fixture-udstyret var tilgængeligt; slutforløbet bruger korrekt indlæst native spiller. Ændringen er kun i smoke-kilderne.
- Kun FOOD_BAR, INFO_BAR og EXPERIENCE_LEVEL får målrettede offsets. XP-/level-offset bruges kun, når Minecrafts aktuelle native bjælke er ExperienceBar. Locator, ride-hop, rustning, luft, ridedyrshelbred og locator-addons beholder løft 29. Den eksisterende accessor læser desuden den allerede initialiserede aktuelle native bjælke uden at skrive noget. Uafhængig review bekræfter layer-rækkefølge, afbalancerede matrixer og uændret fallback; ingen blokeringer.
- Release-JAR har korrekt version 0.3.10, gyldig ZIP-integritet og ingen smoke-klasser. **44 af 48 eksisterende klasser** og alle **58 assets** er byte-identiske med 0.3.9. Alle server-, progression-, evne-, ressource-, lagrings- og netværksklasser er uændrede. `ResourceHudLayout` og ressource-HUD er også byte-identiske. Ingen nye afhængigheder eller ændringer i XP, point, stats eller gemmedata.
- Locator-/ridebar-bevarelse er kontrolleret mod native bytecode/layer-kobling og en regressionstest; disse to native bar-tilstande blev ikke aktiveret i liveforløbet. Ingen ny multiplayer-session er kørt for denne klientlayoutændring. Spiltesten bruger lokal offline-login/virtuel skærm og lukkes manuelt efter COMPLETE. Den almindelige build/test-kommando afslutter med exit 0. Se [HUD_LAYOUT.md](../../HUD_LAYOUT.md).
