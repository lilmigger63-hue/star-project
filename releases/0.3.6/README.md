# Star Swordmaster 0.3.6

Minecraft **1.21.10**, Java 21 og Fabric Loader 0.19.5. Brug samme Fabric API, Better Combat 3.0.0+1.21.10, Player Animation Library 1.1.3 og Cloth Config som i [installationsvejledningen](../../README.md).

Download `star-swordmaster-0.3.6.jar` i denne mappe og udskift den tidligere Star Swordmaster-JAR på klient og server. Behold kun én version. De eksisterende gemmedata, stats og point bevares.

Alle 32 aktive evner har animation og visuelle effekter; 11 originale klip bruger det eksisterende PAL/Better Combat-lag. [Komplet oversigt](../../ABILITY_PRESENTATION.md), [testresultater](VALIDATION.md) og [checksum](SHA256SUMS.txt).
