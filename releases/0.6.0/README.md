# Star Swordmaster 0.6.0

[Download JAR](https://raw.githubusercontent.com/lilmigger63-hue/star-project/main/releases/0.6.0/star-swordmaster-0.6.0.jar) · [SHA-256](SHA256SUMS.txt)

Minecraft **1.21.10**, Java **21**, Fabric Loader **0.19.5+**. Replace the previous Star Swordmaster JAR in `mods`; keep one version. Use 0.6.0 on clients and server.

Existing dependencies: Fabric API 0.138.4+1.21.10, Better Combat 3.0.0+1.21.10, Cloth Config 20.0.149 and Player Animation Library 1.1.3 (`PlayerAnimationLibFabric-1.1.3+mc.1.21.9.jar`, also compatible with 1.21.10).

New: native hand-attached sigils, solid terrain-rising Earth formations, cached cinematic spell geometry, English mod text and dark-fantasy UI polish. Existing progression, saves, 85 nodes, 54 active abilities and individual aura hues are retained.
