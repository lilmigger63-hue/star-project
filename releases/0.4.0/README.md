# Star Swordmaster 0.4.0

Minecraft **1.21.10**, Java 21 og Fabric Loader 0.19.5. Brug Fabric API 0.138.4+1.21.10, Better Combat 3.0.0+1.21.10, PAL 1.1.3 og Cloth Config 20.0.149 fra [installationsvejledningen](../../README.md).

Download `star-swordmaster-0.4.0.jar` og udskift den gamle Star Swordmaster-JAR. Behold kun én version; installer **samme version på klient og server**.

Alle 32 aktive evner har nu særskilte originale PAL-animationer og forskellige visuelle koreografier: klinge-efterbilleder, sværdspor, fartstreger, runesegl, ild, frost, stjerneaura og healing. Seks originale pixelpartikler bruger de eksisterende partikelgrænser og serverbekræftede aktiveringer. Better Combat, skade, priser, timing, progression, gemmedata og HUD bevares.

[Alle animationer/effekter](../../ABILITY_PRESENTATION.md), [testresultater](VALIDATION.md) og [checksum](SHA256SUMS.txt).
