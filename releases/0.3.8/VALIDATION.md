# Validering — Star Swordmaster 0.3.8

## HUD-placeringer i version 0.3.8

Verificeret 16. oktober 2026:
- Java 21 og samme Minecraft 1.21.10/Fabric/Better Combat 3.0.0+1.21.10/PAL 1.1.3 som 0.3.7. `./gradlew --offline build smokeClasses test --rerun` består med **103 JUnit-tests**, nul fejl/spring og **37 selvstændige progressionskontroller**. Ingen nye afhængigheder.
- Seks nye regressionstests dækker venstre skærmforankring ved voksende bredde, smal stabling, kompakt sult/XP over evner, ekstra native rækker, chatudsigt ved flere chatskalaer og creative-genstandsnavne. De tre første fejlede mod det oprindelige 0.3.7-layout før implementering. Creative-tilfældet blev også reproduceret med en fejlet test før rettelsen.
- En rigtig Minecraft-klient og integreret Fabric-server med Better Combat gennemfører **65 kontroller**. Smoke-mixinen observerer de faktiske native teksturkoordinater efter matrix-transformation, så hotbarens ydre markering, XP og sult kontrolleres i selve renderingen. Testkode og capture-mixin indgår ikke i den udgivne JAR.
- Testede vinduer/skalaer: **1280×720/2, 960×720/3, 853×481/1, 640×480/2, 1120×800/2 og 1124×800/2**. De sidste to kontrollerer ombrydningen lige under/ved GUI-bredde 562. Billeder af brede/smalle layouts og chat er visuelt kontrolleret. Panelet står ved venstre kant; XP og sult er over evnebjælken, som fortsat møder native valgt-slots yderkant med præcis nul afstand.
- Samme liveforløb tester faktisk healing, serverbekræftet mana-/staminaforbrug, regeneration og cooldown, uændrede Z/X/C/V/B, H/K, læsende rendering, ekstra liv/absorption, native rustning/luft, F1, spectator og manglende/forsinkede snapshots. Chatklik følger teksten ved chatskala 1 og 0,5, også med maksimal linjeafstand; det gamle klikområde er væk, og udsnittet holder sig inden for skærmen. Creative-genstandsnavnets faktiske renderkoordinat friholder det stablede panel.
- Uafhængig kodegennemgang fandt creative-genstandsnavnets native +14-forskydning; en regressionstest, målrettet kompensation og ny spilkontrol verificerer rettelsen. Gennemgangen bekræfter også matching mellem chatrendering og musekoordinater samt native beregning af ridedyrs-/luftplads. Ingen væsentlige resterende reviewfund.
- Release-JAR har version 0.3.8, gyldig ZIP-integritet og ingen smoke-klasser. **42 af 47 eksisterende klasser** og alle **58 assets** er byte-identiske med 0.3.7. Alle server-, progressions-, evne-, gemme-, attribut- og netværksklasser er uændrede: ubegrænset leveling, ×1,5-XP ved modtagelse fra level 8 og 5 stat-/1 perkpoint bevares. Kun klientlayout og tilhørende rene layoutmodeller ændres. Se [HUD_LAYOUT.md](../../HUD_LAYOUT.md).
- Testmiljøet bruger lokal offline-login og virtuel skærm. Ingen ny samtidig multiplayer-session er kørt for denne rent visuelle ændring; synkronisering/protokol og alle serverklasser er byte-identiske med den tidligere multiplayer-testede udgave. Ridedyr med tre hjerterækker og knappen for ventende chatbeskeder er gennemgået mod Minecrafts bytecode, men ikke aktiveret i liveforløbet. Efter COMPLETE-markøren blev testklienten lukket manuelt; afsluttende exit 130 er ikke et fejlet gameplay-assert. Den almindelige build/test-kommando afslutter med exit 0.
