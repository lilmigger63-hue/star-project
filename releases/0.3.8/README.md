# Star Swordmaster 0.3.8

Minecraft **1.21.10**, Java 21 og Fabric Loader 0.19.5. Brug eksisterende Fabric API, Better Combat 3.0.0+1.21.10, Player Animation Library 1.1.3 og Cloth Config fra [installationsvejledningen](../../README.md).

Download `star-swordmaster-0.3.8.jar` og udskift den tidligere Star Swordmaster-JAR. Behold kun én version; brug samme version på klient og server.

Hoved/level og blå mana/rødt liv/grøn stamina forankres nederst til venstre. Sult står over vanilla-XP i en kompakt gruppe over evnebjælken. Den centrerede evnebjælke møder stadig hotbaren uden mellemrum eller overlap. Smalle vinduer stables; chat, ekstra liv, luft og genstandsnavne får plads.

Leveling uden fast loft, ×1,5-XP fra belønninger modtaget på level 8+, 5 stat-/1 perkpoint og eksisterende gemte data er uændrede. [HUD-layout](../../HUD_LAYOUT.md), [testresultater](VALIDATION.md) og [checksum](SHA256SUMS.txt).
