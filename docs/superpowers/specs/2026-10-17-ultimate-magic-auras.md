Implements both user attachments plus the overriding randomized-color requirement. User authorized direct implementation without further approvals and asked for recommended defaults.

Add16 functional Lightning/Water/Earth/Dark spells, six functional Swordsman techniques, a basic passive aura unlock for rank1, 23 original skill icons,22 original PAL clips, eight reusable animation styles, unique effects, expanded K tree and Danish/English text. Preserve ranks1–4, H, five slots Z/X/C/V/B, old IDs, costs/effects, XP/stat/perk rules and existing saves.

## Integration decisions
- New IDs: static_spark,chain_lightning,thunder_step,heavens_wrath,water_bolt,tidal_wave,aqua_blade,ocean_prison,stone_spike,earthen_wall,quake_blade,worldbreaker,shadow_bolt,curse_mark,shadow_edge,eclipse_nova,astral_crescent,falling_star,phantom_blades,celestial_rush,sovereign_judgment,heavenly_sword_domain. Passive aura_sense unlocks a subtle sword aura before aura_awaken; existing aura_awaken/element_binding also unlock it without extra costs for old players.
- Add Skill.LIGHTNING/WATER/EARTH/DARK. Practice defaults zero in old saves. All abilities use existing authoritative validation, hostile-only targets, resource/cooldown accounting and saves. New spells do not alter terrain, create fire/explosive damage or target pets/allies.
- VisualPowerScaling.power(BigInteger) returns finite monotone0..1, smooth diminishing returns; visual-only dimensions/detail. Safe caps for arbitrarily large levels. Extend presentation events with compact authoritative VisualState and at most8 actual impacted positions (chain paths); no client can choose damage/visual rank.
- AuraColors derives a high-saturation/full-hue HSV color from UUID once per authoritative state construction. No new save field or per-frame RNG. Colors persist across death/reconnect/restart and are transmitted to observers. Rank changes intensity/size/complexity, never base hue. Spellblade elements add secondary accents while preserving the base color.
- Shared VisualState record fields: boolean auraUnlocked,int rank,int swordLevel,float power,PlayerProgress.PlayerClass playerClass,int auraColor,AbilityPresentation.Element element. Element gains LIGHTNING,WATER,EARTH,DARK. ClientVisualState.get(UUID) returns a state (DEFAULT when absent), put(UUID,VisualState) accepts confirmed data, register() installs bounded tracking/world/disconnect cleanup. Server synchronizes self and tracking players on changes/new tracking; no continuous particle streams.
- SwordAuraRenderer.register() installs client-only held-item/first-person hooks. Aura must follow actual transformed sword using item tags, mirror hands, work with PAL/BC, skip UI/dropped items, no duplicate local paths and no lingering history after weapon removal/world switch. Bound all mesh/trail work, cull beyond64blocks; idle cheaper than attacks. Native emissive translucent pixel-art geometry, no external renderer dependency.
- Retain256 new particles/tick,64 active casters,64block draw distance. At most12 primary points plus8 immediate accents per ability update; layer shape/size instead of unlimited counts. Larger effects have a tested12block visual radius cap and3block sprite cap; no larger hitboxes. Distance/vanilla particle mode and Low/Normal/Ultra quality settings further reduce detail. HUD positions do not change.
